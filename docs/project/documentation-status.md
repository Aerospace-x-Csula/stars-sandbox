# Documentation Status

This page tracks the current state of major STARS documentation.

Statuses:

- **Draft** — document exists but has not been fully verified
- **In Progress** — actively being developed
- **Verified** — instructions or technical content have been reviewed and tested
- **Planned** — required later but not yet implemented

| Document | Status | Primary Owner | Technical Reviewer |
|---|---|---|---|
| Documentation Index | Draft | Documentation & Release | Documentation & Release |
| Local Development Setup | Draft | Documentation & Release | Infrastructure |
| Team Roles | Draft | Documentation & Release | Project Lead |
| System Overview | Draft | Documentation & Release | Relevant Sub-Leads |
| Architecture Decision Records | Draft | Documentation & Release | Relevant Sub-Leads |
| Operator Runbooks | Planned | Documentation & Release | Automation / Test Engineering |
| Release Checklist | Draft | Documentation & Release | Project Lead |
| Deployment Guide | Planned | Documentation & Release | Relevant Sub-Leads |
| Rollback Guide | Planned | Documentation & Release | Automation |
| Training/Handoff Material | Planned | Documentation & Release | Project Lead |

## Rule

A document should not be marked **Verified** simply because it has been written.

Verification should include review by the appropriate technical owner and, when the document contains procedures, successful execution of those procedures.
