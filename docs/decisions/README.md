# Architecture Decision Records

Architecture Decision Records (ADRs) document important technical decisions made by the STARS project team.

ADRs help future team members understand not only what was implemented, but why the team chose that approach.

## When to Create an ADR

Create an ADR when a decision:

- affects multiple parts of the system
- changes the architecture
- introduces or replaces an important technology
- creates an important project convention
- has meaningful alternatives
- would be difficult for a future team member to understand without context
